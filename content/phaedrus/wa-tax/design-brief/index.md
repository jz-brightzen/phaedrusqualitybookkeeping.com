## What this site is

**Weekly Accounting Tax** — sister company to Weekly Accounting. Job: clean QuickBooks-grade books → tax AI (Zuni) → senior CPA in the loop → support through the process → file when ready.

**Primary audience:** Existing Weekly Accounting companies. Path is easier from CFO/books into tax than the reverse.

**Primary conversion:** Join the **January waitlist** — not instant checkout until capacity and SKUs are locked.

## Brand relationship

| | weeklyaccounting.com | tax.weeklyaccounting.com |
|--|----------------------|--------------------------|
| Job | Outsourced accounting / fractional CFO / weekly visibility | Tax returns + advice on books already cleaned by WA |
| Tone | Bold, founder-friendly | Licensed trust — dial playfulness down; keep humanity |
| Entity | Weekly Accounting Inc. | Weekly Accounting Tax — **separate company, own insurance** |
| Visual | Golos Text; greens + peach + cream | Sister-brand: same family, Tax lockup, restrained trust UI |

**Never** copy the parent’s “CPAs: Zero” line onto the tax site. **Never** BrightZen-dark.

## Visual system (sister tokens)

| Token | Value | Use |
|-------|-------|-----|
| Deep green | `#04432B` | Headings, primary text, dark CTAs on light |
| Forest green | `#1A3930` | Secondary dark surfaces, footer |
| Warm peach | `#FFBC7D` | Primary filled buttons / waitlist CTA |
| Soft cream | `#FFEDD8` | Soft section backgrounds, cards |
| Warm tan | `#BF967B` | Accents, borders |
| Type | **Golos Text** | Body + UI |
| Buttons | ~30px pill | Large peach or green CTAs |

Mood: light, warm, open whitespace, card grids, numbered steps — plus trust badges without inventing credentials.
